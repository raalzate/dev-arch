# SyntheticIntegrations (synthetic VB.NET legacy fixture)

Synthetic, redistributable fixture written for feature 022-external-integrations: a WCF Service Reference
(`Service References/Ofac`), an ASMX Web Reference (`Web References/Holiday`), a hand-written WCF client
(`ClientBase(Of IPricing)`), a SOAP client (`SoapHttpClientProtocol`), REST calls with a literal URL and a
configuration key, `app.config` client endpoints, `packages.config`, third-party assembly references (one end of
life), a `ProjectReference` to a project missing from the delivery and a Setup project. All names and hosts are
fictitious (`*.example.invalid`); it is not a real system and is not derived from any real code base.
