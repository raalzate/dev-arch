# SyntheticLegacyDebt (synthetic VB.NET legacy fixture)

Synthetic, redistributable fixture written for feature 021-desktop-identity-layers. It imitates a .NET Framework
console/desktop project with a `<RootNamespace>` (types declared in relative `Namespace` blocks), a form inheriting a
third-party form base, a report class with its `.rdlc`, a module with `Sub Main` (batch entry point), a validator,
a repository with concatenated SQL and mixed transaction models, and a static facade large enough to be a god
class. Project-level `<OptionStrict>Off</OptionStrict>`. All names are fictitious; it is not a real system and is
not derived from any real code base.
